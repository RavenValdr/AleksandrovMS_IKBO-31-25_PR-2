# Инструмент визуализации графа зависимостей пакетов (Вариант №1)

CLI-приложение для анализа прямых, транзитивных и обратных зависимостей пакетов в формате **JavaScript (npm)**, а также их визуализации на языке диаграмм **Mermaid** без использования сторонних библиотек и штатных менеджеров пакетов.

## Описание функций и настроек

Параметры передаются через опции командной строки:
* `--package` — имя анализируемого пакета (обязательный параметр). В режиме тестирования — заглавные латинские буквы (`A-Z`).
* `--repo` — базовый URL-адрес реестра (например, `https://registry.npmjs.org`) или путь к JSON-файлу тестового репозитория (обязательный параметр).
* `--test-mode` — флаг включения режима тестирования по локальному файлу описания графа.
* `--version` — анализируемая версия пакета (по умолчанию `latest`).
* `--filter` — подстрока для исключения пакетов: узлы, содержащие данную подстроку в имени, игнорируются при обходе.
* `--stage` — номер этапа (от `1` до `5`, по умолчанию `5`).
* `--show-image` — флаг автоматического рендеринга в PNG и открытия изображения графа на экране (для этапа 5).
